# Vidyadhari High School

Official interactive web portal for **Vidyadhari High School** located in Bhimaram Rural, Telangana.

## Features

- **Cinematic 9-Video Scroll Hero**: High-definition, smooth scroll-locked walkthrough across 9 campus zones with audio toggle and micro-notch slide indicators.
- **Glassmorphic & Transparent Aesthetics**: Campus photography background seamlessly integrated with modern frosted glass UI components.
- **Interactive Admissions & WhatsApp Concierge**: Guided conversational intake flows, direct WhatsApp handoff, and custom messaging support.
- **3D Interactive Campus Walkthrough**: Three.js WebGL-powered 3D visualization of the academic and sports facilities.
- **Full-featured Admin Portal**: Lead management, enquiry status tracking, campus visit schedule manager, and live admissions analytics.
- **Accessible & Performance Optimized**: Built with Next.js 16, React 18, Tailwind CSS, Lucide icons, and zero-warning TypeScript configurations.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Language**: TypeScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/madisettisandeep-art/Vidyadhari-High-School.git
   cd Vidyadhari-High-School
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.
